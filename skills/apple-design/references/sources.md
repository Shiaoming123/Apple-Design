# 来源、覆盖与更新
核对日期：2026-09-11。中文内容是独立归纳，不是 Apple 官方译文。以原始页面为最终来源；未宣称逐字翻译或穷尽全部 SDK 与 WWDC 内容。

## 范围与层级
用户提供链接显示为 materials，实际链接指向 foundations；本版同时核对两页，并上溯至：
- [Apple Design](https://developer.apple.com/design/)
- [Design Pathway](https://developer.apple.com/design/get-started/)
- [HIG](https://developer.apple.com/design/human-interface-guidelines/)
- [Design Resources](https://developer.apple.com/design/resources/)
- [What’s new](https://developer.apple.com/design/whats-new/)

HIG 六个主要分支：
| 分支 | 本 Skill 覆盖 |
| --- | --- |
| [Getting started](https://developer.apple.com/design/human-interface-guidelines/getting-started) | 八项原则、iOS/iPadOS/macOS/tvOS/visionOS/watchOS、游戏、iPhone Duo |
| [Foundations](https://developer.apple.com/design/human-interface-guidelines/foundations) | 18 项基础主题，见视觉与输入参考 |
| [Patterns](https://developer.apple.com/design/human-interface-guidelines/patterns) | 25 项用户流程主题，见交互参考 |
| [Components](https://developer.apple.com/design/human-interface-guidelines/components) | 内容、组织、动作、导航、呈现、输入、状态、系统体验八组，见组件参考 |
| [Inputs](https://developer.apple.com/design/human-interface-guidelines/inputs) | 13 种输入主题，见输入参考 |
| [Technologies](https://developer.apple.com/design/human-interface-guidelines/technologies) | 29 项技术体验，包括 AI、同步、身份、健康、媒体与系统集成 |

基础、模式、输入与技术主题已读取官方结构化指导提纲；材料、可访问性以及主要平台另核对正文，常用组件读取指导提纲。组件参考中部分低频叶子页为目录定位与工程选型摘要，使用时仍需读取其正文。不要把“已索引”表述成“所有细则已验证”。

## 官方与工程边界
官方主张、平台限定及建议条件都应保留；“consider/prefer”不能无条件改成禁止或必须。
Web token、ARIA、测试矩阵、优先级和组件实现属于工程映射。WCAG 声明按实际标准验证，不能只根据 HIG 表格推断。
官方设计资源、字体、图标、商标、支付按钮的使用条件随各资源而定。提供来源不转移资产许可。没有把官方原文或图片打包为本 Skill 的资源库。

## 读取与更新
更新时访问相应官方页面与 Change log，遵守适用条款；不要把可访问的 DocC 数据路径解释为再分发许可。本版公开包不提供原文提取或镜像脚本。无法读取时报告未核验，不冒充最新正文。
新增页面、组件、跨平台与交付手册属于原创工程解释；可运行示例的值和布局不是官方标准。具体许可与风险见 [PROVENANCE.md](../PROVENANCE.md)。
