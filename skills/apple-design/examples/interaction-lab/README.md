# 可运行的交互实验

原创离线示例：列表选择 → 编辑标题 → 校验 → 模拟失败 → 重试 → 返回。没有外部字体、图片、网络请求或生产数据依赖。

从本目录使用任意静态 HTTP 服务打开 index.html，例如：

```powershell
python -m http.server 18542 --bind 127.0.0.1
```

访问 http://127.0.0.1:18542 。模块脚本需要 HTTP 服务，不保证 file:// 双击运行。

## 操作步骤
1. 点击“编辑标题”，初始焦点落在任务标题。
2. 输入空白并保存：显示错误，焦点仍在字段。
3. 输入新标题，勾选“模拟本次保存失败”，保存后草稿仍在，取消勾选自动发生。
4. 重试成功，列表与详情同时更新，焦点返回编辑按钮。
5. 修改但未保存时按 Escape：先出现放弃确认；“继续编辑”保留输入。
6. 打开深色与减少透明度，缩窄到 390px，再放大浏览器或 CSS 文字，观察换行与可达性。

## 明确的简化
数据只在内存中，刷新会还原。失败是显式模拟，不代表真实网络恢复；没有用户权限、并发修订、持久化和同步。不要把此示例当成生产级任务管理器。
演示的断点、色值和圆角是原创示例值，不是 Apple 标准。原生 dialog 行为仍需在目标浏览器/WebView验证。
没有手写焦点陷阱；借助原生 dialog.showModal，并处理标题、初始焦点、关闭保护与焦点恢复。已具有成熟 OverlayManager 的产品不必替换为此示例。
